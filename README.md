# 艾泽拉斯任务档案 · WoW Quest Archive

面向任务设计研究与 AI 检索的魔兽世界资料库：五个常用客户端版本、逐字段简中优先、可离线使用的网页和可直接读取的 JSONL。

**在线查阅：[打开艾泽拉斯任务档案](https://zzz1999.github.io/wow-quest-archive/)**，无需下载或启动本地服务。首次选择某个版本时会下载该版本的数据包；书签保存在当前浏览器。

**下载并解压整个项目，双击根目录 `index.html` 即可查阅。** 网页不依赖账号、数据库、CDN 或联网资源。请使用较新的 Chrome、Edge、Firefox 或 Safari；不要只下载一个 HTML 文件，也不要在压缩包内直接打开。

如果浏览器限制本地文件，可在项目目录运行 `npm run serve`，再打开 <http://127.0.0.1:4173>。这只是本机静态文件服务，使用 Node.js 20+，不需要 `npm install`。

## 可以查什么

- 任务标题、目标摘要、接取描述、进行中 / 交物品对白、完成 / 奖励对白。
- 任务 ID、等级、最低等级、区域 / 分类 ID、任务类型、接取和交付 NPC / 物件。
- 点击接取 / 交付处的名称打开 NPC 档案，查看中文名、英文名、称号、模板等级及关联任务；顶部“NPC 档案”可按名称、称号或 ID 搜索，也可切换查看任务物件。
- NPC 档案顶部同样提供“在 Wowhead 查看”，按当前版本和 NPC ID 打开中文 NPC 页面，便于查看位置与更多信息；使用新标签页，保留当前档案和原任务。版本对应规则与任务入口一致。
- 前置与后续字段、奖励后续、引导关系；点击关系可跳转任务。
- 任务详情顶部的“在 Wowhead 查看”会在新标签页打开对应任务的中文页面：经典旧世、巫妖王之怒、大地的裂变、潘达利亚之谜分别使用 `classic`、`wotlk`、`cata`、`mop-classic` 数据库，军团再临使用正式服数据库。此入口需要联网；Wowhead 的现行资料可能与本库的历史快照不同，也可能没有对应任务。已确认的社区自定义任务不显示该入口。
- 任务详情顶部的“返回上一任务”可沿查阅路径逐步回退，恢复筛选、列表分页与滚动位置、已展开信息和正文阅读位置；支持浏览器后退 / 前进及刷新后继续返回。直接打开的首条任务没有返回目标。
- 英文原文、字段实际语言、原始来源表 / 列、采集 build，以及奖励 / 条件原始字段。
- 每个版本使用多个同版本数据源补充文字；“原始资料”中可按字段查看实际数据库来源及匹配依据。
- 双栏模式下任务列表随页面保持可见、独立滚动；阅读长任务时仍可在左侧查找下一条。
- 按版本、关键词、标题语言、区域 ID、等级和正文筛选；浏览器本地书签。
- 单任务 JSON、可复制文本，以及当前筛选全部结果的 JSONL 导出。
- 单份 NPC / 物件档案 JSON，以及当前筛选档案的 JSONL 导出。
- 默认“玩家视角”：`$N` / `$n`、`$C` / `$c`、`$R` / `$r` 分别显示为“名字”“职业”“种族”小标签，样式与语言标签一致，悬停可查看原始变量。可在“阅读设置”填写角色资料，标签内随之显示角色的名字、职业和种族；性别称呼也可选择。编号与来源信息收在“原始资料”中；也可切换“原文视角”查看未经代入的文字。
- 特殊标记使用说明标签，并提供可展开的“游戏变量说明”。需要实时数据的标记显示为“实时数值”；尚未核实的变量不猜填身份。比如 `$ct` 不再被拆成“职业 t”，`$vg他:她;` 会并列显示“他 / 她”并解释原因。
- “复制当前文本”按当前阅读视角复制，并标明是否代入了称呼。JSON / JSONL 导出始终保留原始文字和游戏变量。阅读设置只保存在当前浏览器。

## 收录快照

| 版本 | 客户端 | 任务记录数 | 主要来源 |
| --- | --- | ---: | --- |
| 经典旧世 | 1.12.1–1.12.3 | 4,245 | CMaNGOS Classic-DB |
| 巫妖王之怒 | 3.3.5a | 9,464 | AzerothCore |
| 大地的裂变 | 4.3.4 | 14,907 | MaNGOS Three |
| 潘达利亚之谜 | 5.4.8 | 18,144 | alexkulya/pandaria_5.4.8 |
| 军团再临 | 7.3.5 | 29,716 | TrinityCore TDB735.00 |
| **合计** | **5 个版本** | **76,476** | **按版本 + ID 计数** |

后期版本包含保留下来的早期任务，所以合计不代表 76,476 个独立故事。资料是固定的社区数据库快照，不保证每条任务可接取、可完成，也不声称是官方完整任务全集。

另收录 **22,896 份 NPC 档案、2,904 份任务物件档案**，按版本、类型与 ID 独立保存。范围是这些任务静态接取 / 交付关系中引用的对象，不是完整生物图鉴。经典旧世的 NPC 中文使用同一固定提交内的 Chinese 本地化表；例如任务 7 的接取与交付者为“治安官玛克布莱德”（NPC 197）。

每个字段依次尝试 **简体中文 → 繁体中文 → 英文**。缺失保留为空，不补写剧情、不自动翻译。没有汉字的中文表英文占位值不计为汉化；损坏字符会触发继续回退并记录 `textIssues`。完整语言覆盖统计在网页“来源与收录情况”和 [reports/coverage.json](reports/coverage.json)。

五个版本均使用同版本补充来源，按英文标题和对应内容保守匹配。第一轮补充见 [文字检查报告](docs/TEXT-AUDIT.md)。第二轮新增 MaNGOS Four、The Legion Preservation Project 和 Legion Proyect 中文资料，在上一轮基础上改善 **40,863 个文字字段**，涉及 **15,743 条任务**。军团再临现有 **22,799 个简中标题、664 个繁中标题、6,165 段中文进行中对白和 8,629 段中文完成对白**；潘达利亚简中标题增至 **15,874**。结果、来源与剩余缺口见 [中文补充报告](docs/CHINESE-TEXT-AUDIT.md)。

已知资料限制：大地的裂变有部分旧译文（已确认任务 2，网页提示翻译待核）；潘达利亚部分中文来自较晚客户端采集，另有 **116 条已核实的社区自定义任务**，默认隐藏；军团仍有英文与空白字段，新增对白大量标记为 build 0，不能视为已核实的官方逐字文本。详见 [数据字典](docs/DATA.md)。

## 文件入口

```text
index.html                 本地网页入口
web/                       样式、交互与压缩数据包
data/<version>/*.jsonl      UTF-8 任务记录，每行一个任务，约每千条一片
data/<version>/actors/*.jsonl  NPC 与任务物件档案，含双向任务关系
data/<version>/manifest.json
reports/coverage.json      每个字段的语言、缺失统计与分片哈希
reports/text-audit/        多源补充前后统计与逐字段匹配记录
reports/chinese-upgrade.json  第二轮相对上一版的中文增量统计
sources/manifest.json      固定提交、下载 URL、SHA-256、处理顺序与许可
sources/licenses/          上游许可证、署名与版权原件
docs/DATA.md               字段、回退规则、限制与复现方法
docs/TEXT-AUDIT.md         第一轮文字检查记录
docs/CHINESE-TEXT-AUDIT.md  第二轮中文补充与变量显示说明
docs/AI-RESEARCH.md         给 AI 的检索与研究建议
scripts/                   不依赖第三方包的导入、构建与校验工具
```

版本目录名为 `classic`、`wotlk`、`cataclysm`、`pandaria`、`legion`。使用 `version:id` 引用资料，例如 `wotlk:5846`。网页链接片段 `#wotlk/5846` 可以定位任务。

NPC 档案主键形如 `classic:creature:197`；网页链接为 [`#classic/npc/197`](https://zzz1999.github.io/wow-quest-archive/#classic/npc/197)。物件使用 `#版本/object/ID`。它们可以直接分享和收藏。

## 研究和维护

AI 使用先阅读 [docs/AI-RESEARCH.md](docs/AI-RESEARCH.md)，按研究问题检索少量任务，并保留版本、来源与缺失信息。原始资料与研究者新增的分析标签应分开保存。

```sh
npm test                   # SQL 解析、逐字段回退、版本边界与关系映射
npm run validate           # 全量数据、哈希、编码、统计和浏览器副本一致性
npm run build              # 从 JSONL 重新生成离线网页数据包
node scripts/rebuild.mjs    # 从固定源完整重建；需要联网及解压工具
```

普通浏览无需安装任何依赖。完整重建需要 Node.js 20+、ZIP 解压工具及 7-Zip（用于军团发布附件），并会在 `.cache/` 保存原始资料。所有上游 SQL 只作为数据读取，绝不执行。

在线站点使用 GitHub Pages，从 `main` 分支根目录发布。`.nojekyll` 保证 HTML、JavaScript 和数据文件按原样提供；推送到 `main` 后 GitHub 会自动更新网站。下载后的离线入口仍为 `index.html`。
