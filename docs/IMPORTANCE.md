# 重要任务标记

任务列表中的金色“◆ 重要”标记用于快速查找主线剧情、职业关键任务、重要功能解锁和传说任务。悬停可查看分类，详情中显示具体原因和可展开的依据；“更多筛选 → 仅看重要任务”可与版本、阵营、重复类型等条件组合。

这是**任务档案的编辑分类**。五个历史版本没有一套相同、完整的“重要任务”字段，所以不能把标记当作各版本官方统一定义，也不能把没有标记理解为“不重要”。当前涵盖可核对的分类、能力奖励和一批关键剧情 / 解锁节点，尚不是所有主线及其前置任务的完整清单。

## 数据分类规则

- **传说任务**：任务类型 `83`，或同版本任务分类 `Legendary`。类型依据各版本固定核心的 `QuestDef.h` / `SharedDefines.h`，军团也由固定 `QuestInfo` 表核对。历史核心来源见 [接取条件说明](QUEST-TRAITS.md#来源与复现)。不把单纯奖励橙装、稀有度、长任务链或高等级视为传说任务。
- **主线剧情**：同版本明确的战役分类（例如熊猫人战役、要塞战役、抗魔联军战役），以及史诗分类和人工核对的关键节点。一般任务链关联位不等于主线；普通日常 / 周常不会仅因位于战役分类下就被选入。
- **职业关键任务**：军团神器类型 `107` / 神器分类、各职业战役的非重复任务，以及经典和巫妖王中有职业限制、奖励关联已核对能力的任务。能力名单覆盖形态、姿态、驯兽、恶魔召唤、救赎、制毒、图腾和部分职业移动能力；普通职业限制、普通增益和任意奖励法术不足以触发标记。
- **重要功能解锁**：人工核对的副本钥匙 / 准入 / 传送入口、阵营据点、世界任务、资料片入口和能力节点。理由中的“任务线”表示在取得该功能的过程中，不表示这一步独立解锁全部内容。

分类名称和来源来自 [区域名称档案](REGIONS.md) 的同版本表；职业能力引用 [奖励档案](REWARDS.md) 中已有的法术 ID、角色和来源。不会借用正式服新增的重要任务类型，也不会把相同 ID 的其他版本标记搬过来。隐藏追踪记录、未核对的测试记录及已知社区自定义内容不参与自动分类。

## 人工核对条目

人工条目保存在 [annotations/importance-rules.json](../annotations/importance-rules.json)，每一组固定版本、任务 ID、英文标题、分类、理由和参考来源；生成时必须匹配该版本的 ID 与英文标题，否则构建失败。

当前条目包括：经典黑龙阴谋与奥妮克希亚准入线、黑石塔 / 黑石深渊 / 通灵学院钥匙、熔火之心与黑翼之巢入口；巫妖王的天谴之门、幽暗城之战、死亡骑士节点、阵营据点与影之哀伤；大灾变的世界之柱与开篇引导；潘达利亚远征与锦绣谷入口；军团开篇、联合势力与阿古斯远征。

核对依据包含该版本档案的任务正文、目标、完成对白与奖励。黑龙任务线的叙事范围另参考 [经典时期剧情整理](https://warcraft.wiki.gg/wiki/World_of_Warcraft_endgame_and_patch_storylines)，巫妖王关键节点参考 [巫妖王战役整理](https://warcraft.wiki.gg/wiki/Wrath_of_the_Lich_King_campaign)。这些网页用于确认故事范围，不替换任何历史任务文本。

“联合势力”的世界任务解锁依据 [暴雪军团世界任务说明](https://worldofwarcraft.blizzard.com/en-us/news/20252892/legion-world-quests-and-you)；“命运之手”和维迪卡尔的阿古斯开篇依据 [暴雪 7.3 阿古斯战役预览](https://worldofwarcraft.blizzard.com/en-us/news/20979713)。按历史版本解释，不能据此保证当前正式服或所有私服的接取方式。

## 维护与离线使用

`npm run build` 从规则、同版本区域分类和原始任务生成 `annotations/importance/<version>.json`、`web/importance-data.js` 与 [覆盖报告](../reports/quest-importance.json)。报告按版本统计任务和分类，分类允许重叠。`npm run validate` 重算并核对所有条目、统计与网页副本。

标记与理由已保存到离线包。查看标记无需联网；外部参考链接需要联网。原始任务 JSONL、语言回退、阵营与重复规则保持原值；复制当前文本会附上“档案重点”，原始 JSON / JSONL 导出不混入编辑分类。研究时需要重点标签，可通过版本与任务 ID 关联 `annotations/importance/`，保留其理由和依据。
