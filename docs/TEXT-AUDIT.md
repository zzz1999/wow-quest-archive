## 匹配与复核边界

- 只使用同客户端版本、主库已有 ID；英文标题必须匹配。其他字段还必须匹配对应英文，或在主库英文缺失时匹配非空描述/目标上下文。
- 简中优先于繁中和英文，同语言优先主库；已存在的简中不由补充库覆写。原有英文对照保留。
- 424 个同 ID 候选因英文标题不匹配而排除；1,693 个潜在改善字段因英文或上下文不匹配而排除。排除是保守保护，并不判定某一来源一定错误。
- 每个采用字段的 ID、来源、语言变化和匹配依据见 [classic](../reports/text-audit/classic.json)、[wotlk](../reports/text-audit/wotlk.json)、[cataclysm](../reports/text-audit/cataclysm.json)、[pandaria](../reports/text-audit/pandaria.json)、[legion](../reports/text-audit/legion.json)。`before` / `after` 可直接比较所有字段覆盖。
- 这些规则不能证明每句翻译正确，也不等于逐句人工审校。已知的大地的裂变任务 2 地点旧译文继续标记“翻译待核”；潘达利亚较晚采集文本、社区自定义记录仍保留原有标识。
- 多个库可能共享早期资料。CMaNGOS Classic 与 WotLK 中文文件哈希相同，不是独立译文互证。LegionCore README 明示其核心源自 UWOW 2020 泄露版本，该社区来源已独立标记并保留许可/来源声明，不能据此推断官方性或使用授权。

## 网页空白区域

截图中左侧大块空白来自布局：列表的最大高度固定，而整列被右侧长正文撑高。双栏界面现将左侧目录固定在可视区内，列表占据剩余高度并独立滚动；手机单栏保留紧凑列表。点击任务仍保留列表滚动位置，任务关系和后退功能继续可用。

## 复现与核验

固定下载地址、提交和 SHA-256 见 [sources/manifest.json](../sources/manifest.json)。执行 `node scripts/rebuild.mjs` 会分别校验并读取主库与补充库、重建 JSONL、检查报告和离线网页副本。SQL 只作为数据解析；自定义 DELIMITER 下的存储过程整段忽略，不执行过程内的 UPDATE。

自动测试覆盖版本隔离、英文匹配、语言回退、同语言优先顺序、自定义任务排除、来源记录和 SQL 存储过程边界。全量校验核对 76,476 条任务、22,896 份 NPC、2,904 份物件档案的哈希、语言、来源、反向关系与网页副本。另与补充前提交逐条比较：任务身份、非文字字段、原有主库文字与英文对照、NPC / 物件档案均保持一致；只有被报告列出的文字字段发生预期改善。
