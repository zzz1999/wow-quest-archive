## 剩余限制

军团仍有 6,246 个英文标题、3,715 段英文进行中对白、11,681 段英文完成对白；另有 19,836 个进行中字段、9,406 个完成字段为空。空白可能是未收录，也可能是自动任务、可选对白或测试记录本来就没有这段文本，不能据此补写内容。

新中文来源是社区快照，多个库可能共享材料。TDB735.25051 的中文对白大量使用 build 0；Legion Proyect 具有 LegionCore/UWOW 派生背景。语言标签和英文匹配只能说明来源选择，不能证明译文为官方逐字文本。上游许可与来源声明保留于 `sources/licenses/` 和 `DATA-LICENSE.md`。

本轮逐条比对 76,476 条任务：任务身份、等级、奖励、关系、NPC / 物件档案、主库英文及已有简中保持不变。420 个军团字段原先的英文对照来自补充库，主库该字段为空；本轮选择中文后，对照改为该中文来源携带的英文，并同步更新 `englishSources`。这是补充来源之间的对照调整，不应表述成所有英文逐字不变。

## 截图中的变量

截图为 `legion:9065`。原文含 `$ct`、`$vn` 和 `$vg他:她;`。旧显示把 `$ct` 拆成 `$c` 加字母 `t`，导致“职业 t”；现在先识别完整标记，显示“特殊变量”。`$vn` 显示“游戏变量”，其身份含义未核实；`$vg他:她;` 并列显示“他 / 她”，不按玩家性别猜测所指对象。

正文下的“游戏变量说明”可展开，列出原始标记、已知含义或未知原因。名字、职业、种族继续使用原有徽标；世界状态数值与军衔变量提供对应提示。原文视角和 JSON / JSONL 仍保留原始变量，复制玩家视角文本时特殊标签附上原始标记。

## 复现与核验

`sources/manifest.json` 固定源提交、附件路径、SHA-256、语言与 build 限制。运行 `node scripts/rebuild.mjs pandaria` 和 `node scripts/rebuild.mjs legion` 可重新生成数据与全量多源报告。`npm test` 覆盖 SQL 字面量、语言边界、build 过滤、英文匹配和变量展示；`npm run validate` 校验全量哈希、字段来源、语言/build 限制、关系和网页副本。
